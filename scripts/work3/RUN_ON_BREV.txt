1) Upload this zip into the P4 project root, then unzip so scripts land in scripts/work3/ :
     cd /home/nvidia/24PHD1237/P4_SEEDV_COGNITIVE_BIOMETRIC
     unzip -o P4_work3_experiments.zip -d scripts/          # -> scripts/work3/*.py

     python -u scripts/work3/11_band_recompute_from_windows.py 2>&1 | tee outputs/work3/logs/11_band.log

     python -u scripts/work3/15_reve_linear_probe.py           2>&1 | tee outputs/work3/logs/15_reve.log
     python -u scripts/work3/16_aep_spectral_theta.py          2>&1 | tee outputs/work3/logs/16_aep.log

4) Send back: outputs/work3/logs/*.log  and  outputs/work3/*/*.csv
   (or just paste the console output). Verified numbers then go into the paper.
